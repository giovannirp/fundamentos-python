## 🎯 Objetivo

O objetivo deste repositório é **praticar Python na prática**, transformando conceitos teóricos em código através de:

- 📖 Exercícios
- 💻 Exemplos de código
- 🧩 Pequenos desafios
- 🚀 Projetos práticos
- 📝 Materiais de estudo

A ideia é manter uma evolução gradual, começando pelos conceitos básicos e avançando para estruturas e recursos mais complexos da linguagem.
